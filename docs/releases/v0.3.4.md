## ADB WiFi Installer v0.3.4

### 変更点
- ファイルエクスプローラーの削除ボタンで、不要な確認ダイアログを表示せず削除します
- ファイルとフォルダをドラッグ＆ドロップして、現在表示しているディレクトリへアップロードできます。フォルダの階層を保持します
- アップロードの二重実行を防ぎ、移動後に古い処理が表示を巻き戻さないよう改善しました
- 一部のアップロードが失敗した場合も一覧を更新し、エラーを表示します
- ブラウザテストの起動・終了処理とネイティブAPIのモックを修正しました

### 配布・検証
- この配布は Windows x64 向けです。ADB（Android SDK Platform Tools）が必要です
- Windows のインストーラー、Tauri updater署名、更新マニフェストを配布します
- macOS 版は既存の署名・公証環境で別途ビルドが必要で、このリリースには含まれていません
- フロントエンド41件、ブラウザのスモークテスト7件、Rust6件が修正後に通過しています
- 実機のWindows/macOSアプリとAndroid端末を接続した操作確認は未実施です
